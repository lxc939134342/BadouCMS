### 介绍

八斗网站管理系统，简称：BadouCMS，基于 ThinkPHP8+Layui 的开源网站管理系统，支持多语言、多模型、多条件搜索、内容权限、会员功能、文章评论、文章内链、百度推送、轮播图、多条件筛选、网站地图等。

> 本项目实现了 pbootcms 的基本功能，功能使用与 pbootcms 基本类似。
