# 幻灯片标签 `slide` 与友情链接标签 `link`

原始来源：`slide.md`、`links.md`。二者均全站可用，且 `gid` 必填。

## `slide`

参数：`gid`（必填，分组 ID）、`num`（默认 5）、`alias`、`empty`、`key`、`mod`。

字段：`n`、`i`、`id`、`pic`、`link`、`title`、`subtitle`。

## `link`

参数：`gid`（必填，分组 ID）、`num`（默认 10）、`alias`、`empty`、`key`、`mod`。

字段：`n`、`i`、`id`、`name`、`logo`、`link`。
