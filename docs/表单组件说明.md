## 图片上传组件

```html
<input type="text" id="c-ico" name="row[ico]" lay-verify="required" class="layui-input" value="{$row.ico}" />
<div class="layui-input-suffix" style="width: 30%;">
    <button type="button" data-input-id="c-ico" data-preview-id="p-ico" class="layui-btn btn-bdupload">
        <i class="fa fa-upload"></i>
        上传
    </button>
    <button type="button" data-input-id="c-ico" class="layui-btn layui-bg-green btn-bdchoose">
        <i class="fa fa-list"></i>
        选择
    </button>
</div>
<div class="layui-upload-list" id="p-ico"></div>
```

> data-input-id 填充数据文本框的 id
>
> data-preview-id 显示图片的 id
>
> data-multiple 多图片

## 远程下拉框

```html
<!-- 存储下拉选择后的值 -->
<input type="hidden" id="c-group" name="row[group]" value="" class="layui-input" />
<!-- 调用远程下拉框 -->
<div
    class="remoteSelect"
    id="remoteSelect-group"
    data-input-id="c-group"
    data-primary-key="id"
    data-verify="required"
    data-vertype="msg"
    data-reqtext="验证提示内容"
    data-field="name"
    data-source="auth.admin/getGroupList"
    data-is-tree="true"
    data-pidname="pcode"
    data-multiple="true"
    data-params='{"key":"value"}'></div>
```

> id 表示当前的远程下拉
>
> data-input-id 用于存储下拉选择后的值表单 id 如：c-group
>
> data-primary-key 表主键
>
> data-field 显示的字段
>
> data-source 远程请求的链接
>
> data-is-tree 是否开启树型
>
> data-pidname 树型 pid
>
> data-multiple 是否多选
>
> data-params 链接携带的额外参数
>
> data-verify="required" 验证
>
> data-vertype="msg" 设置验证异常时的提示层模式 同 lay-vertype 用法一致
>
> data-reqtext="验证提示内容" 验证提示内容

> url 返回值的结构

```json
{
    "code": 1,
    "msg": "ok",
    "data": {
        "count": 3,
        "list": [
            {
                "id": 1,
                "name": " 超级管理组"
            }
        ]
    }
}
```
