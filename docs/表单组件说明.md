## 图片上传组件

```html
<input type="text" id="c-ico" name="row[ico]" lay-verify="required" class="layui-input" value="{$row.ico}" />
<div class="layui-input-suffix" style="width: 30%;">
    <button type="button" data-input-id="c-ico" data-preview-id="p-ico" class="layui-btn btn-bdupload">
        <i class="fa fa-upload"></i>
        上传
    </button>
    <button type="button" data-input-id="c-ico" class="layui-btn layui-bg-green btn-bdchoose">
        <i class="fa fa-list"></i>
        选择
    </button>
</div>
<div class="layui-upload-list" id="p-ico"></div>
```

> data-input-id 填充数据文本框的 id
>
> data-preview-id 显示图片的 id
>
> data-multiple 多图片
