## 初始化

```html
bdTable.api.init({ table: treeTable, // layui 表格对象，支持普通table与树结构table extend: { index_url: "auth.rule/index", //获取表格数据 add_url: "auth.rule/add", //添加数据 edit_url: "auth.rule/edit", //编辑数据 del_url: "auth.rule/del", //删除数据 multi_url: "auth.rule/multi", //批量处理 table: "auth_rule", //数据表名称 }, });
```

### 高级搜索

> 在列元素中增加

| 参数              | 默认值 | 说明             |
| ----------------- | ------ | ---------------- |
| commonSearch      | true   | 是否开启高级搜索 |
| searchFormVisible | false  | 高级搜索保持显示 |

### 列元素

> 在 layui 的列元素中扩展了属性 [https://layui.dev/docs/2/table/#options.cols](https://layui.dev/docs/2/table/#options.cols)

| 参数       | 值                                                                                                                                                      | 说明                   |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| operate    | 默认：=<br/>不在搜索中显示：false<br/>支持 `!=、LIKE、NOTLIKE、>、<、>=<=、FIND_IN_SET、IN、NOTIN、BETWEEN、NOTBETWEEN、RANGE、NOTRANGE、NULL、NOTNULL` | 用于高级搜索时的操作符 |
| searchType | remoteSelect 远程下拉<br/>between 区间搜索<br/>time 时间搜索                                                                                            | 搜索的表单类型         |
| extend     | 无                                                                                                                                                      | 填写 html 扩展属性     |

### 表格数据格式化

单元格数据渲染：使用 layui 表格的`templat:bdTable.api.formatter.icon`

| 方法                                  | 参数                                                                                            | 说明           |
| ------------------------------------- | ----------------------------------------------------------------------------------------------- | -------------- |
| bdTable.api.formatter.icon            | 无                                                                                              | 渲染成图标     |
| bdTable.api.formatter.switch          | 无                                                                                              | 渲染成开关     |
| bdTable.api.formatter.status          | custom:{<font style="color:rgb(75, 77, 78);">"值":"颜色标签"</font>} searchList:{"key":"value"} | 渲染状态       |
| bdTable.api.formatter.status.flag     | custom:{"值":"颜色标签"}, customField:"自定义字段", searchList:{"new":"新","hot":"热门"}        | 渲染不同的标识 |
| bdTable.api.formatter.status.datetime | datetimeFormat:"yyyy-MM-dd HH:mm:ss"                                                            | 格式化时间     |

### remoteSelect 使用

```html
searchType:'remoteSelect', extend:' data-source="auth.rule/selectpage" //远程下拉链接 data-field="title" //显示字段 data-multiple="false" //是否开启多选 data-is-tree="1" //开启树型 '
```
