# BadouAdmin 钩子（Hooks）扩展指南

本文档详细介绍了 BadouAdmin 系统中可用的钩子（Hooks）及其使用方法。通过钩子机制，您可以在不修改系统核心代码的情况下，扩展系统功能或自定义界面。

## 1. 什么是钩子？

钩子（Hooks）是系统在特定执行点触发的一种事件机制。插件或模块可以“监听”这些钩子，并在触发时执行自定义代码。

- **调用钩子**：`hook($name, $params, $is_return)`
- **检查钩子**：`has_hook($name)`

---

## 2. 字段扩展钩子（核心扩展）

这些钩子允许您自定义 CMS 的表单字段和渲染逻辑。

| 钩子名称 | 调用位置 | 作用 | 参数说明 |
| :--- | :--- | :--- | :--- |
| **`cms_extfield_type`** | `Extfield` 模型 | **注册自定义字段类型**。允许插件在后台“字段管理”中增加新的类型选项。 | `&$options`: 字段配置定义数组 |
| **`cms_field_custom`** | `fields.html` 模板 | **渲染自定义组件 HTML**。当系统遇到未知组件时调用。 | `field`: 字段信息, `row`: 当前行原始数据 |

### 示例：实现一个视频播放器字段

**第一步：注册类型**
在插件的 `AppInit` 或事件监听器中：
```php
\think\facade\Event::listen('cms_extfield_type', function(&$options) {
    $options['20'] = [
        'text' => '视频播放', 
        'inputType' => 'video', 
        'type' => 'string', 
        'limit' => 255, 
        'default' => ''
    ];
});
```

**第二步：渲染 HTML**
```php
\think\facade\Event::listen('cms_field_custom', function($params) {
    if ($params['field']['component'] == 'video') {
        // 返回视频播放器的 HTML 模板
        return View::fetch('your_plugin@video_player', $params);
    }
});
```

## 3. 界面扩展钩子（UI 增强）

用于在后台管理页面的特定位置注入自定义按钮或 HTML 元素。

| 钩子名称 | 页面位置 | 作用 |
| :--- | :--- | :--- |
| **`admin_top_begin`** | 后台主框架顶部 | 导航栏最左侧注入元素（如消息提醒）。 |
| **`admin_top_end`** | 后台主框架顶部 | 导航栏最右侧注入元素。 |
| **`content_top_btn`** | 文章列表 / 单页列表 | 在管理列表顶部增加自定义按钮。 |
| **`content_sort_top_btn`** | 栏目分类列表 | 在栏目管理页面顶部增加自定义按钮。 |
| **`cms_label_top_btn`** | 变量/标签列表 | 在 CMS 标签管理页面顶部增加自定义按钮。 |
| **`module_top_btn`** | 模型管理列表 | 在模型管理页面顶部增加自定义按钮。 |

---

## 4. 功能检测钩子

用于检查系统中是否启用了某些特定功能或插件。

| 钩子名称 | 用途 |
| :--- | :--- |
| **`editor`** | 检查系统是否安装了富文本编辑器插件。 |
| **`sms_send`** | 检查系统是否启用了短信发送功能。 |

---

## 5. 如何使用钩子

在 BadouAdmin 中，您通常在插件的入口类（如 `YourPlugin.php`）的 `AppInit` 方法中注册监听器：

```php
public function AppInit()
{
    // 监听特定钩子
    \think\facade\Event::listen('content_top_btn', function(){
        return '<button class="layui-btn layui-btn-sm">插件按钮</button>';
    });
}
```
